# Fit-Gate Redirection Examples

These examples illustrate ASMP **Fit and Redirection Gate** behavior. They are not canonical scope artifacts.

---

## Example A — Trivial task redirected to lighter treatment

**Initial request:** "Help me scope adding a copyright year update to the website footer."

**Gate evidence:** Single line change, one owner, immediately reversible, no coordination, no decision value from a formal scope document.

**Recommendation:** Lighter action-oriented approach — make the edit directly or track as a one-line maintenance task.

**Outcome:** No `IDEA-SCOPE.md` produced. Person approved redirection. Useful intake (file location, current year) carried forward into the edit.

**Lesson:** ASMP Compact should not create ceremony when formal scoping adds no decision value.

---

## Example B — Compact work redirected to Comprehensive

**Initial request:** "Scope a small app to help our clinic share patient vaccination records with partner organizations."

**Gate evidence (material signals):**
- Privacy and health-data exposure
- Multiple organizations with different systems
- Regulatory duties around PHI
- Difficult-to-reverse trust and compliance commitments

**Recommendation:** ASMP Comprehensive — stakeholder diversity, evidence burden, and lifecycle needs exceed Compact fit.

**Outcome:** Person approved redirection. Intake notes (clinic context, partner list) preserved. Scoping continued under Comprehensive, producing a full Scope Map.

**Lesson:** "Small app" language does not override consequence. Physical size or feature count is not the only complexity measure.

---

## Example C — Comprehensive redirected to Compact

**Initial request:** "Scope migrating our entire county health data platform."

**Initial protocol:** ASMP Comprehensive (person supplied it).

**Gate evidence (after intake):** Person clarified they only need to scope migrating **one report export** from the platform, not the platform itself. Single owner, reversible, one deliverable.

**Recommendation:** ASMP Compact — original framing overstated the work unit.

**Outcome:** Person approved redirection to Compact. Comprehensive checkpoint files were not started. Scope Brief produced for the export migration only.

**Lesson:** Re-check fit when intake clarifies the actual work unit. Redirection can go toward lighter treatment, not only heavier.

---

## Using these examples

When validating ASMP behavior manually, confirm:

1. Redirection is explained with evidence before switching protocols.
2. Explicit approval is requested.
3. Useful intake carries forward.
4. The final artifact matches the approved scoping mechanism.
5. No Banka-specific steps appear unless explicitly requested after scope completion.
