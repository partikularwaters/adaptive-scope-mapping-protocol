# Adaptive Scope Mapping Protocol — Comprehensive

**Protocol version:** v0.2.0-draft — 2026-10-11

---

> [!NOTE]
> **Single-file canon retired.** Neither Compact nor Comprehensive remains one monolithic file. Large files cause prompt drift and loss of context in agentic workflows.
>
> ASMP has moved to a **stepped ingestion architecture** for file-capable environments alongside a **portable single-ingest edition** for plain chat surfaces:
>
> 1. **File-capable agent runtimes / IDEs:**  
>    Start with the entry router: [`protocols/comprehensive/ROUTER.md`](comprehensive/ROUTER.md)  
>    Step files (loaded progressively): [`protocols/comprehensive/steps/`](comprehensive/steps/)
>
> 2. **Plain chat surfaces with no persistent file tools:**  
>    Use the portable single-ingest protocol: [`protocols/comprehensive/PORTABLE.md`](comprehensive/PORTABLE.md)
